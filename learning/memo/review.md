# レビュー

「はじめに」の章はここで終わりです。ここまでで以下のことができるようになっているはずです。

- ウィンドウの作成
- シェーダーの作成とコンパイル
- バッファオブジェクトやユニフォームを通じた頂点データの送信
- オブジェクトの描画
- テクスチャの使用
- ベクトルと行列の理解
- カメラ付きの3Dシーンの作成

これらの知識をすべて組み合わせられるようになりました。

ここ数章でかなり多くのことを学びました。学んだことを使って色々試し、自分なりのアイデアで問題を解いてみてください。内容をしっかり理解できたと感じたら、次の「ライティング」の章に進みましょう。

# 用語集

| 用語 | 説明 |
|------|------|
| **OpenGL** | 各関数のレイアウトと出力を定義するグラフィクスAPIの正式な仕様 |
| **GLAD** | OpenGLの関数ポインタをすべて読み込んでセットする拡張ローディングライブラリ。これにより（モダン）OpenGLの全関数が使える |
| **ビューポート** | レンダリング先となる2Dウィンドウ領域 |
| **グラフィクスパイプライン** | 頂点が画面上の1つ以上のピクセルになるまでに通る全工程 |
| **シェーダー** | GPU上で動く小さなプログラム。パイプラインの複数ステージでユーザー製シェーダーに差し替えられる |
| **頂点 (Vertex)** | 1点を表すデータの集合 |
| **NDC（正規化デバイス座標）** | クリップ座標にパースペクティブ除算を行った後に頂点が収まる座標系。-1.0〜1.0の範囲内の頂点のみ描画される |
| **VBO（頂点バッファオブジェクト）** | GPU上にメモリを確保し、頂点データをすべて保持するバッファオブジェクト |
| **VAO（頂点配列オブジェクト）** | バッファと頂点アトリビュートの状態をまとめて管理するオブジェクト |
| **EBO（要素バッファオブジェクト）** | インデックス描画用のインデックスをGPU上に保持するバッファオブジェクト |
| **ユニフォーム** | GLSLのグローバル変数の一種。シェーダープログラム内のすべてのシェーダーからアクセス可能で、一度セットするだけでよい |
| **テクスチャ** | シェーダー内で使う特殊な画像。通常オブジェクトに貼り付け、非常に細かいディテールがあるように見せる |
| **テクスチャラッピング** | テクスチャ座標が(0, 1)の範囲外になったときにOpenGLがどうサンプリングするかを決めるモード |
| **テクスチャフィルタリング** | 複数のテクセル（テクスチャピクセル）から選ぶ際にOpenGLがどうサンプリングするかを決めるモード。主にテクスチャ拡大時に発生する |
| **ミップマップ** | 視聴者との距離に応じて適切なサイズが選ばれる、縮小済みテクスチャを複数保持したもの |
| **stb_image** | 画像読み込みライブラリ |
| **テクスチャユニット** | 複数のテクスチャを異なるユニットにバインドすることで、1つのシェーダープログラムで複数テクスチャを扱えるしくみ |
| **ベクトル** | 任意の次元で方向や位置を定義する数学的な実体 |
| **行列 (Matrix)** | 変換に有用な数式の長方形配列 |
| **GLM** | OpenGL向けに設計された数学ライブラリ |
| **ローカル空間** | オブジェクトが最初に存在する空間。すべての座標がオブジェクトの原点からの相対値 |
| **ワールド空間** | すべての座標がグローバル原点からの相対値 |
| **ビュー空間** | カメラの視点から見たすべての座標 |
| **クリップ空間** | カメラ視点にプロジェクションを適用した座標空間。頂点シェーダーの出力はここに収まる必要がある。残りはOpenGLがクリッピングとパースペクティブ除算を行う |
| **スクリーン空間** | 画面から見たすべての座標。範囲は0〜画面の幅/高さ |
| **LookAt** | 特殊なビュー行列の一種。指定した位置から指定したターゲットを見るように、すべての座標を回転・平行移動する座標系を作る |
| **オイラー角** | Yaw・Pitch・Rollの3値で任意の3D方向ベクトルを表現できる角度の表し方 |
